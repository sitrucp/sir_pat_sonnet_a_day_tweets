# @SirPatStew #ASonnetADay tweet links and Twitter audience interest

Sir Patrick Stewart shared Shakespeare sonnet readings from his home during the COVID-19 lockdown. This dashboard provides:

- A dot chart of each sonnet tweet's likes and retweets.
- A sortable table of tweets with links to watch them.

[View the dashboard](https://sitrucp.github.io/sir_pat_sonnet_a_day_tweets/)
